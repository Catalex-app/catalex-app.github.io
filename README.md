# Catalex website

The official website for Catalex, an open-source, local-first LaTeX workspace for you and your agent.

[Visit the website](https://catalex-app.github.io/) · [Get Catalex](https://github.com/Catalex-app/Catalex/releases) · [App repository](https://github.com/Catalex-app/Catalex)

Documentation and changelog content come from the app repository. Each page includes a complete snapshot and checks its Markdown source once when opened. If that request fails, the snapshot remains available. New documentation routes appear with the next website build.

See [asset credits](docs/design-provenance.md) for artwork, fonts, and media sources.
